# ChimeraX Interface Visualization

Generates a commented `.cxc` script for ChimeraX that produces a publication-quality
view of a PPI interface. The target protein is the visual focus; the binder is
rendered as a translucent ghost. Hotspot residues stand out with opaque surface
patches and sphere representation.

No tool calls are made. All inputs are extracted from the context report.

---

## Phase 1: Extract Inputs from Context Report

From the prior complex-structure-analysis or binder-optimizer report, extract:

| Field | Source in report |
|---|---|
| `file_path` | COMPLEX OVERVIEW → Structure |
| `target_chain` | COMPLEX OVERVIEW → Target chain |
| `partner_chain` | COMPLEX OVERVIEW → Partner chain |
| `hotspot_residues` | HOTSPOT REGIONS → Residues (auth_seq_id list) — primary patch only |
| `interface_residues` | TARGET CHAIN INTERFACE RESIDUES + all hotspot regions (union) |
| `hbond_pairs` | H-BONDS AT INTERFACE table — donor and acceptor residue numbers |
| `label_residues` | Top 4–6 hotspot residues with highest BSA (most important to label) |
| `complex_name` | Infer from protein names in report (used in script header comment) |
| `structure_source` | COMPLEX OVERVIEW → Structure source |

If any field is missing, use a safe fallback:
- Missing `interface_residues`: use `hotspot_residues` only
- Missing `hbond_pairs`: omit the `hbonds` command
- Missing `label_residues`: label the top 3 hotspot residues

|---|---|---|---|
| Target chain (cartoon) | Steel blue | `#2E86C1` | Main chain color |
| Target interface surface | Steel blue, 50% transparent | `#2E86C1` | Broad interface region |
| Hotspot patch (surface) | Amber | `#E67E22` | Primary hotspot, 20% transparent |
| Hotspot patch (atoms) | Amber | `#E67E22` | Sphere style, same residues |

| Background | White | — | |
| Labels | Dark slate | `#2C3E50` | |

If the user requests a different palette, substitute consistently across all elements.

## Phase 3: Generate the Script

Produce a fully commented `.cxc` script. Follow the block structure below exactly.
Fill in all residue lists as comma-separated integers with no spaces (e.g. `52,56,98,103`).

```
# ============================================================
# ChimeraX Visualization — <complex_name>
# Structure: <file_path>
# Target chain: <target_chain> | Partner chain: <partner_chain>
# Generated by little_protein_tiger chimerax-visualization
# ============================================================

# --- Setup ---
open <file_path>
windowsize 1400 1000
set bgColor white
lighting soft

# --- Base representation ---
hide atoms
cartoon #1
color #1 #AAAAAA

# --- Target chain: <target_chain> ---
color #1/<target_chain> #2E86C1
transparency #1/<target_chain> 0 cartoons

# Molecular surface on full target interface region
surface #1/<target_chain>
color #1/<target_chain> #2E86C1 target s
transparency #1/<target_chain> 50 surfaces

# Hotspot patch: opaque surface + sphere atoms
color #1/<target_chain>:<hotspot_residues> #E67E22
color #1/<target_chain>:<hotspot_residues> #E67E22 target s
transparency #1/<target_chain>:<hotspot_residues> 20 surfaces
show #1/<target_chain>:<hotspot_residues> atoms
style #1/<target_chain>:<hotspot_residues> sphere

# --- Partner / binder chain: <partner_chain> (ghost) ---
color #1/<partner_chain> #BDBDBD
transparency #1/<partner_chain> 40 cartoons
surface #1/<partner_chain>
color #1/<partner_chain> #D5D8DC target s
transparency #1/<partner_chain> 55 surfaces

# --- H-bonds at interface ---
# (omit this block if no hbond data was in the report)
hbonds #1 restrict both reveal true color #F4D03F showDist false

# --- Labels on key hotspot residues ---
label #1/<target_chain>:<label_residues> residues text "{0.label_name}{0.label_number}" color #2C3E50 height 0.6


# --- Focus view on hotspot ---
view #1/<target_chain>:<hotspot_residues> pad 0.7
turn y 15

# --- Save image ---
# Adjust path as needed; supersample 3 gives 3× resolution for publication
save <output_dir>/<complex_name>_interface.png width 2560 height 1440 supersample 3
```

## Common Pitfalls

- **Residue spec syntax**: ChimeraX uses `#model/chain:resnum` — no spaces around `/`
  or `:`. Comma-separated resnums with no spaces: `#1/A:52,56,98` not `#1/A:52, 56, 98`.

- **auth_seq_id vs label_seq_id**: use **auth_seq_id** values from the report for all
  ChimeraX residue specs — these match the PDB author numbering in the file.

- **surface before color**: `surface #1/A` must be called before `color #1/A surface ...`
  and `transparency #1/A ... surfaces`. Surface creation and coloring are separate commands.

- **transparency target keywords**: use `cartoons` (plural) and `surfaces` (plural) as the
  target argument: `transparency #1/B 70 cartoons`, `transparency #1/B 85 surfaces`.
  Using singular forms (`cartoon`, `surface`) is a common error and will fail silently.

- **hbonds with no cross-chain contacts**: if `restrict both` returns no bonds, the command
  silently succeeds with nothing shown — this is fine, not an error.

- **`style sphere` vs `style ball`**: `sphere` renders atoms at full Van der Waals radius
  (bulky, very visible). Use `ball` for a subtler look. For hotspot emphasis, `sphere` is
  usually preferred.

- **turn y 15**: adds a slight rotation after `view` to reveal interface depth. Adjust or
  remove if the default orientation already shows the interface clearly.

- **save path**: use an absolute path or a path relative to where ChimeraX is launched.
  The `supersample 3` flag renders at 3× then downsamples — required for publication quality.
